# EduFix

Concept of a student dashboard (red and white design). Single static page, no build step.

## Run
Open `index.html` in a browser, or serve the folder:

    npx serve .

## Features
- My Subjects, Error Analysis, Courses, Tests: add your own data
- Personal 7-day retake plan built from the weakest topics
- AI Assistant chat (demo answers, no real AI connected)
- Progress calculated from added data

Data is kept in memory only and resets on page reload.
